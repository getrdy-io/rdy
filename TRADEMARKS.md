# Trademark policy

"Rdy", "rdy" and the Rdy logo are trademarks of Apostolic Path LLC. The code is open source under Apache-2.0.
The names and the logo are not part of that grant. Section 6 of the license says so, with one exception:
you may use the name to say where the code came from.

This policy lets you use the name in the ways that help people, and stops uses that would confuse them.

## You may, without asking

- Say, truthfully, that your software works with rdy, or that an environment was checked by rdy.
- Link to the project at https://github.com/getrdy-io/rdy or https://getrdy.io.
- Redistribute an official release unmodified, under its own name. Official releases are the signed
  archives on the GitHub releases page of `getrdy-io/rdy`, and the `rdy` crates we publish on crates.io.
  Keep the `LICENSE` and `NOTICE` files with them.
- Package an unmodified tagged release under the name rdy, with only the changes your package system
  needs to build it. Say where it came from.
- Write about rdy: reviews, tutorials, talks, comparisons. Use the name as plain text.

## You may not

- Name a fork, product, company, domain or service "Rdy", or something that looks or sounds like it.
  Adding a word does not fix this. "Rdy Pro" and "RdyCheck" are still confusing.
- Use the logo.
- Suggest that we make, approve, sponsor or endorse your work when we do not.
- Present a modified build as an official release, or ship it under the official release name.

## Forks

You can fork the code. The license allows it. A fork that you publish or distribute as its own project
must use a different name: in the binary name, the package names, the docs and the release files. Say that
it is based on rdy. Keep the copyright and `NOTICE` text as the license requires. A fork on GitHub that you
use to send us a pull request can keep the name.

## Specs and vendors

Rdy checks an environment against a vendor's signed spec. A vendor may say that its spec is "for rdy".
That is a true statement and it is fine. The vendor's own name goes on the spec, not ours.

## Questions

If you are not sure, ask. Email security@getrdy.io and put "trademark" in the subject line. That is the
address in `SECURITY.md`. It is the same inbox as security reports, so the subject line matters.
