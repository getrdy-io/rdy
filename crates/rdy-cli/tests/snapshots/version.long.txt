Print the version

Prints the version, the commit and the build date. Put this in a bug report.

Usage: rdy version [OPTIONS]

Options:
      --json
          Print the fields as JSON on stdout

      --color <WHEN>
          Colors: auto, always, never [default: auto]

      --progress <WHEN>
          Live progress: auto, never [default: auto]

  -q, --quiet
          Print less

  -v, --verbose
          Print more

  -h, --help
          Print help (see a summary with '-h')

Example output:
  rdy 0.1.0 (4c1e9a2 2027-03-07)
