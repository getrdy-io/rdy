Run `rdy run` with a spec that holds `k8s.storageclass`, `k8s.rbac`, `k8s.nodes`, `k8s.admission` or `k8s.namespace`: the Kubernetes family now builds each from its parameters, so they run against your cluster and are no longer skipped as not in the build. `as:` and the OpenShift fix text of `k8s.rbac` now work in a real run.
