- `rdy run <spec>` now runs. It verifies the spec, makes a private report folder, runs the host checks that exist, skips the rest as "not built yet", writes the JSON report and exits 0, 1 or 2 by the verdict. With `--json` the report is on stdout and is the same bytes as the file. The report records who ran it from the privilege check, and a result with no advice of its own shows the check's general fix.
