- A spec is refused with exit 64 when it has no checks, more than 256 checks, names more than 64 distinct hosts across `net.egress`, `net.tls_intercept` and `net.dns`, or names more than 256 distinct host and port pairs across `net.egress` and `net.tls_intercept`. An unknown key in `metadata` or `bundle` now says which block it is in. A `bundle.collect` item that is not `journal:<duration>`, `k8s:events` or `file:` with an absolute path and no `..` is refused.
- `rdy-spec` refuses a spec whose `metadata.expires` has passed (`SpecError::Expired`, both dates in the message). The CLI wiring (`spec_expired`, exit 64) comes with M1-126. `rdy-spec` adds `load_at` to pin the clock in tests, and clippy bans it everywhere else. An empty `metadata.version`, a `bundle.redact` name or `redact_patterns` name that breaks the schema pattern, and a backslash in a `file:` collector path are refused.
- Kubernetes names and label-key prefixes are checked one dot-separated part at a time, and `net.dns` and `expect_in` have more refuse cases.
