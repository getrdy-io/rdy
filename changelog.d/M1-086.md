- `rdy run` now prints its result as a readable report on stderr: a header, the checks sorted by bucket with a fix line under each problem, the summary, the report folder and the verdict as the last line. Colour follows `--color`, `NO_COLOR` and the terminal, and text from the machine or the spec is printed with control characters escaped.
- An unsigned spec now gets the full UNSIGNED SPEC banner before any check, and its first line again above the verdict.
