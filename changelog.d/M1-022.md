- `rdy version --json` prints the version, commit, commit date, target and rdy-spec version as JSON. The `rdy/v1` JSON schemas are now generated from the `rdy-spec` types, and CI fails when they are stale. The `file:` rule of `bundle.collect` now compiles in every JSON Schema validator. `rdy-spec` has a new `schema` feature, off by default, that holds the schema generator, so `schemars` is not in a normal build. `rdy_engine::End::Done` now holds a `Box<CheckOutcome>`, which changes a public type of `rdy-engine`.
