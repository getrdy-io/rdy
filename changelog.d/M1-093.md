- Network checks can now send one `HEAD` or `GET` to a host the spec lists. The engine verifies an `https` host against the system trust store (or the bundled public roots when the spec says `trust: bundled`) before it sends anything, follows no redirect (it reports the redirect's host), and reads at most 64 KiB of the reply body and throws it away. A reply keeps only its status, six headers and timings. The engine can also report where the system trust store was read from and the SHA-256 of each root.
