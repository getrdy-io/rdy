- Read the parameters of the seven host checks (`host.cpu`, `host.memory`, `host.disk`, `host.ports`, `host.lsm`, `host.security_agents`, `host.os`) into typed values in rdy-spec. A host check with no threshold, such as a bare `- id: host.memory`, is skipped as unsupported with the reason `no_threshold`, and a key with no value (`min:`) is a bad value.
