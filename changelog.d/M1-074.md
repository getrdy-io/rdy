- Every command except help and version now takes the privilege snapshot first. A setuid `rdy`, an `rdy` with file capabilities or one started with ambient capabilities exits 70 before it reads a spec or the trust store.
- A file capability with only the permitted bit (`setcap cap_net_raw+p`) is now refused too, and a binary that hides its own `/proc` entry gets a fix line that names `ls -l` and `getcap`.
