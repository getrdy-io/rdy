- Commands that checks start now run under a fixed policy: programs resolve only from `/usr/sbin:/usr/bin:/sbin:/bin` plus declared directories, and only if the file and its directories belong to root or the running user and are not group- or world-writable. Shells, `sudo`-like tools and programs that run other programs (`env`, `xargs`, `timeout`) are refused, the environment is cleared, and children get a `0077` umask. Descriptors that `rdy` inherits from its shell still reach children until the start-up warning (M1-168) and the close (M2-104) land.
