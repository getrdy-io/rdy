- `rdy run` now ends a hung run. If a check never returns, or `--json` output goes to a pipe nobody reads, rdy stops itself 10 seconds after the run deadline with exit 70, writes a partial report marked incomplete into the report folder, and kills the commands it started (on Windows only the command itself, not its children, until M2-006). With `--json`, a report that is printed and then cannot be written to disk can say `complete: true` with exit 70: trust the exit code.
