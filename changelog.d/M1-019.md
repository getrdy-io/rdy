- Add two-step check decoding to rdy-spec. `CheckSpec::decode_params` gives typed parameters, `Unknown` for a check id this rdy does not have, or `Unsupported` with the field or value it could not read, so one bad check skips one check and never fails the spec. A check entry with no `id` or the same `id` and `name` twice is now an error with a line and column. A `timeout` outside 1s to 60s and a `fix` outside 1 to 2000 characters now make that one check unsupported.
