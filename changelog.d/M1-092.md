- Network checks can now read the TLS certificate chain a host presents and tell whether this machine trusts it. The engine reads the system trust store (PEM bundles on Linux, the keychains on macOS, the root store on Windows; `SSL_CERT_FILE` and `SSL_CERT_DIR` are read as PEM under the file rules, and on Windows they make the check say to unset them), caps it at 1024 certificates of 16 KiB each and 8 MiB of files, and judges the chain against it and against the bundled public roots. The handshake sends no request or credential, the server name is always the host the spec lists, and there is no revocation check.
