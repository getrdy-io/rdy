- Network checks can now read the TLS certificate chain a host presents and tell whether this machine trusts it. The engine reads the system trust store (PEM bundles on Linux, the keychains on macOS, the root store on Windows), caps it at 1024 certificates of 16 KiB each, and judges the chain against it and against the bundled public roots. The handshake sends no request or credential, the server name is always the host the spec lists, and there is no revocation check.
