- Read the parameters of 14 more check ids into typed values in rdy-spec: `host.firewall`, `host.time_sync` (with `ntp_servers`), `host.sysctl`, `host.container_runtime`, `host.cgroups`, `host.kernel`, `net.registry`, `net.mtu`, `net.bandwidth`, `k8s.namespace`, `k8s.dns`, `k8s.ingress`, `k8s.crds` and `k8s.cni`. They are no longer `not_in_build`. A key a type does not have is still refused by name, and a spec that names one of these ids with such a key is now `unsupported_spec`. The spec reference page and the JSON schema list them. The host family lists the six host ids.
