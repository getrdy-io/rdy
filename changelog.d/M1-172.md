- Read the parameters of 14 more check ids into typed values in rdy-spec: `host.firewall`, `host.time_sync` (with `ntp_servers`, `max_skew` and `recommended_skew`), `host.sysctl`, `host.container_runtime`, `host.cgroups`, `host.kernel`, `net.registry`, `net.mtu`, `net.bandwidth`, `k8s.namespace`, `k8s.dns`, `k8s.ingress`, `k8s.crds` and `k8s.cni`. They are no longer `not_in_build`. A key a type does not have is still refused by name, and a spec that names one of these ids with such a key is now `unsupported_spec`. NTP servers, registry hosts and the bandwidth URL count toward the 64 host limit. The spec reference page and the JSON schema list them. `host.firewall` now runs from the host family. On `net.tls_intercept`, `a.example` and `a.example:443` now count as the same host. `host.time_sync` refuses a `recommended_skew` greater than `max_skew`.
