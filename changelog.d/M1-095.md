- Add the `net.egress` check code. For each endpoint it times the name lookup, the connect to every address (IPv6 first) and the TLS handshake, names a dead IPv6 or IPv4 address, and reports the TLS version, ALPN and trust. Failures say which stage broke (`dns`, `refused`, `blackhole`, `tls_unknown_issuer`, `clock_or_expiry`, `reset_after_hello` and more) and what to ask the network team for. It runs in `rdy run` and is skipped under `--no-network`. It sends no HTTP request and does not use a proxy yet.
