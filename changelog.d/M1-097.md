- `rdy run` now reads `HTTPS_PROXY` and `HTTP_PROXY` (either case). `net.egress` goes through the proxy when one is set (`via_proxy: auto`), tunnels `host:port` and `https` endpoints with `CONNECT`, and sends `http://` URLs to the proxy in the absolute form. New classes `proxy_403`, `proxy_407`, `proxy_refused`, `proxy_bad_reply` and `proxy_unreachable` each have a fix. The proxy password never reaches the report.
- A proxy URL that does not parse in those variables is exit 64 with a fix. A proxy password too short to hide is exit 70. `net.egress` also records the host of a redirect (not followed) and says to add it to the endpoints.
