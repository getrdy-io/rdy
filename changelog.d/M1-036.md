- Add the report folder rules. `rdy` writes only into one new folder, `rdy-report-<product>-<time>/`, made before the first check with mode 0700. Files inside are 0600, are never written through a symlink, never replace another file, and get their final name only when complete. A taken folder name moves to `-2` up to `-9`. The product name is checked again before it is used in a path. The spec loader now keeps the bytes it verified (`VerifiedSpecBytes`, read with `LoadedSpec::verified_bytes`), so the copy in the folder is the verified text and not a re-read of the file.
