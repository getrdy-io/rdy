- `rdy spec lint <spec>` reports every problem with its line and column, a fix line and a did-you-mean for a mistyped key, nested key or check id. It exits 0 when clean, 1 for warnings and 2 for errors. `--json` prints a `LintReport` on stdout.
- Lint compiles the regexes of `net.tls_intercept` and `k8s.access`. A `bundle.redact_patterns` regex that does not compile or matches the empty string is refused (exit 64 on `run`). `acme-inference-gpu.yaml` names `k8s.device_plugins`, an id the catalog has.
