- Ctrl-C, SIGINT and SIGTERM now stop `rdy` with exit 70, the two-line error `interrupted. No report was written.` (and an `interrupted` error object with `--json`), kill the commands it started and remove the report folder if it is still empty. A signal at a password prompt puts the terminal back first. Core dumps are turned off for the process. A partial report on the first Ctrl-C comes in 0.2. On Windows the same path is built but not yet tested, and the empty folder may stay. New public items in `rdy-engine`: `watchdog::RawStream`, `watchdog::write_raw_bounded`, `OutputDir::remove_if_empty` and `OutputDir::into_removed_if_empty`.
