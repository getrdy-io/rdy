- Add the `host.sysctl` check. It reads kernel parameters from `/proc/sys` and the `sysctl.d` files in boot order. It blocks on a wrong live value, a missing parameter, or a systemd open files limit that is too low. It warns when a right value is not persisted, or when a masked or later file sets it back. It needs no root and does not run in `rdy run` yet.
