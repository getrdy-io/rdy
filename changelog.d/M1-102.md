- Add the Kubernetes client layer to `rdy-checks-k8s`, for the Kubernetes checks that follow. `rdy run` does not call it yet: M1-107 wires it in. It reads `--kubeconfig`, `KUBECONFIG`, `~/.kube/config` or the in-cluster config, builds a rustls client with the check timeout, and shows the context, server and kubeconfig user before the first request. With no kubeconfig it reports `no kubeconfig found` and the hint. Credential plugin output never reaches an error or a log line, at any log level, and a plugin only talks to the terminal when stdin and stderr are both terminals. A kubeconfig with a legacy `auth-provider` or a cluster `proxy-url` is refused for now.
