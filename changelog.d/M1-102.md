- Add the Kubernetes client layer to `rdy-checks-k8s`. It reads `--kubeconfig`, `KUBECONFIG`, `~/.kube/config` or the in-cluster config, builds a rustls client with the check timeout, and shows the context, server and kubeconfig user before the first request. With no kubeconfig it reports `no kubeconfig found` and the hint. Credential plugin output never reaches an error or a log line, at any log level. A kubeconfig with a legacy `auth-provider` or a cluster `proxy-url` is refused for now.
