- Add the release build. Pushing a version tag builds `rdy` for Linux x86_64 and aarch64 (static musl), macOS x86_64 and arm64, and Windows x86_64, with checksums, a CycloneDX SBOM and the dependency list embedded in each binary for `cargo audit bin`. Before a release is created, a check proves the Linux binaries are static-pie, that `rdy.exe` imports no `VCRUNTIME140.dll`, and that the hashes, archives and SBOM are sound.
