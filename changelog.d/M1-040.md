- Checks now reach the machine only through a per-check probe handle. Every file read, directory listing, stat and command is recorded in the report's action log, with secrets in the entries redacted and counted, including the value after a secret flag such as `--password`.
- The probe refuses reads of password and sudo files, ssh, kube and cloud credential files, private key files, cluster node credentials, most of `/proc/<pid>/`, kernel files and `/dev`. A command runs only if the check declared it and the command table lists it, and a shell or `sudo` never runs. A call made after its check has ended is refused and logged.
- The action log keeps every refused call. Repeated refused or failed file calls under one directory fold into one entry with a count, and one check can hold at most 1000 entries.
