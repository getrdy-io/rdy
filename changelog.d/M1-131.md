- Add `rdy trust add`, `rdy trust list` and `rdy trust remove`. `add` shows the key id and the fingerprint in groups of four and asks before it saves (`--yes` skips the question, `--note` adds a note). With no terminal and no `--yes` it exits 64 and saves nothing. It takes a `.pub` file or the key text and refuses a secret key. A normal user writes `~/.config/rdy/trust.yaml` and root writes `/etc/rdy/trust.yaml`. `list` prints every trusted key, `remove` takes one out (`--key-id` when a product has two). On Windows `trust add` and `trust remove` exit 64: trust stores are not supported there yet.
