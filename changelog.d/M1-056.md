- Redact what rdy prints. Log lines (`RUST_LOG`) and error messages now pass through the redactor before they reach stderr, so a secret in a log field, an environment variable or a kubeconfig is shown as `[REDACTED:...]`. Without `RUST_LOG`, rdy logs nothing, and with it set the noisy libraries (hyper, h2, rustls, tower, kube) still log at warn at most. A panic no longer prints the default Rust text: a panic inside a check becomes an `ERROR` result, and any other panic prints the two lines `error:` and `fix:` (and the JSON error object with `--json`) and exits 70.
