- Add the list of reserved check ids to rdy-spec and the lint rule for check entries. A reserved id this rdy lacks (`host.kernel`, `gpu.cuda`) is a `not_in_build` warning. A misspelled id (`host.memroy`) or an unreadable entry (`mn: 32Gi`) is an error with a fix, and signing refuses it. A known check with no threshold, such as a bare `- id: host.memory`, is a `no_threshold` error that names the missing key.
