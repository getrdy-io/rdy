- Add trust store loading and saving. rdy reads `/etc/rdy/trust.yaml` as root, and your user file then the system file otherwise. It refuses a store or a store folder that is a symlink, owned by the wrong user, or writable by others, with `trust_store_insecure` and a fix line. On Windows it refuses any existing trust store until the permission checks arrive. The result now carries the fingerprint of the key that signed the spec.
