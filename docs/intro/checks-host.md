You can use this page to fix each host finding. Each section names one check, what it measures, what it needs and the fix text that rdy prints for it.

rdy runs host checks on the machine where it runs. Each check lists what it needs. A check that needs root says so, and rdy runs the checks it can without it.

The Remediation text is the general fix for the check. A finding can carry a more specific fix of its own. When it does, rdy prints that fix instead.

Check the Systems line before you rely on a check. A check that is not built for your operating system is skipped, and rdy says so in the result.

The Reads line lists the paths each check reads. It is one list for every operating system. rdy does not yet list the reads for each system on its own.
