# Changelog

All notable changes to `rdy` are listed here, newest first.

Entries are written as fragments. Each PR adds one file, `changelog.d/<ticket>.md` (for example
`changelog.d/M1-003.md`), with one or two bullet lines in plain, user-facing words. Do not edit this
file in a PR. The release ticket collects the fragments under the new version heading and deletes them.

Versions follow `docs/plan/06-release-and-distribution.md`. Before `0.1.0` the tags are `0.1.0-alpha.N`.
